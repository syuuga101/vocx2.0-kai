# Vocx & Dojo

## Dojo・試験練習

2つのUnitを範囲に、英文空欄のプルダウン選択8問と単語入力7問、計15問を11分で解きます。選択問題は12語の共通リストから解答します。Unit 19〜27の180語に、教材の例文1問と独自の練習文4問、計900問を登録しています。1範囲は40語・200問。毎回15語を重複なく抽選し、それぞれの語について5例文のいずれかを抽選します。実際の先生の試験問題を再現したものではありません。保存した試験を再開するときは例文を変更しません。

Unit 19–20から26–27まで利用可能です。27–28・28–29・29–30はUnit 28〜30の教材が未追加のため開始できません。PCでは英文の右に選択欄、スマートフォンでは英文の下に解答欄を配置します。

開始時に途中保存があれば「途中から再開／新しく挑戦」を選べます。新しく挑戦すると、教材から問題・並び順・選択リストを再抽選し、解答と制限時間をリセットします。準備はプログレスバーで表示し、完了後に効果音設定に従う3秒カウントダウンで開始します。準備とカウントダウン中は制限時間を消費しません。開始前にキャンセルした場合、以前の途中保存は残ります。

解答は自動で端末内に一時保存します。「終了」では「保存して終了／保存せず終了／問題に戻る」を選べ、確認中は時間を止めます。保存して終了すると問題・解答・残り時間・スクロール位置を保って再開でき、保存せず終了すると今回の挑戦の途中データを削除します。過去の最高点・全問正解回数は残ります。保存できない場合は通知し、そのまま再試行できます。

採点するまで正解は表示せず、11分経過時には自動採点します。入力は大文字・小文字と前後の空白を除いて照合し、例文に必要な活用形のスペルで判定します。端末をまたいだ進捗同期はありません。既存のDojo学習履歴は削除せず、新しい試験練習を別に保存します。

## Tango・単語帳

上部の`Tango`から教材（Vocx / Dojo）とUnitを選ぶと、そのUnitの単語帳を確認できます。Vocxは各Unit、Dojoは試験範囲の2つのUnitをまとめた単語・日本語の意味・定義・例文を表示します。

単語・意味・例文の検索と「意味を隠す」に対応しています。単語帳を開いてもクイズの進捗は変わりません。

Tangoを初めて開くと、登録済みの試験日程から次の範囲のDojo単語帳を自動で展開します。日本時間の試験終了時刻で次の範囲へ切り替わります。今回は2026年10月20日〜12月22日のスクリーンショットの日程を`study-plan.js`に登録しています（12月8日は画像の記載どおり22:56終了）。一覧では該当範囲を先頭にし、Vocx側でも対象の2つのUnitを先頭にします。別の範囲へ移動した後は「この範囲へ」で戻れます。全日程終了後は過去の範囲を自動推薦しません。教材未追加の場合は準備中と表示します。

Dojo単語帳の「例文 5問・解説」で5例文をまとめて確認でき、追加例文の語句も検索できます。自分で開いた別の単語帳は同じページ内では保持し、日程によって強制的に移動させません。

四択の正解位置は、各位置を1回ずつ使うランダムな組を繰り返して配置します。選択肢数ごとに出現回数の差を最大1回に抑え、組の境界でも同じ位置が連続しないようにしています。保存済みの中断問題は配置を変えず、新しく開始する出題から適用します。

スマートフォン向けの英単語・問題演習アプリです。HTML / CSS / JavaScriptで動作します。

Vocxの「鬼モード」は、ユニットの20語を1回ずつ出題し、日本語→英単語4択・英文空欄4択・英文空欄入力をランダムな順番で混ぜます。各形式は6〜7問ずつです。途中保存・再開と全問正解の記録にも対応しています。

## ファイル構成

- `index.html`：画面構造
- `ui.css`：テーマ・レイアウト
- `app.js`：出題・判定・保存・操作
- `dojo-exam.js`：Dojo試験問題の生成・試験用紙・採点・保存
- `dojo/examples.json`：Unit 19〜27の追加例文（単語ごとに4問、`_____`が解答箇所）
- `study-plan.js`：試験日程と日本時間での次回範囲判定
- `data.js`：学習データのフォールバック
- `vocx/`・`dojo/`：学習データ
- `sw.js`：PWAキャッシュ。配信ファイルを更新するときは`CACHE_NAME`も更新します。
- `sys/`：使用中のPWA・モードアイコンと英字フォント（ライセンス同梱）
- `se/`：効果音
- `debug.js`：ローカル開発用のデバッグ操作（公開版から除外）
- `scripts/`：Node.jsで実行する簡易検証

## 学習データの更新

`vocx/*.csv`・`dojo/*/part*.json`を編集したら、`node scripts/build-data.cjs`で軽量な`data.js`を再生成します。直接HTMLを開く場合やオフライン時も最新データを使えるよう、生成したファイルも一緒に保存してください。HTTP配信時は引き続きCSV・JSONを読み込みます。

PWAは画像・通常の音声取得をキャッシュ優先、HTML・CSS・JavaScript・学習データはネットワーク優先で読み込みます。更新時は`sw.js`の`CACHE_NAME`を変更してください。

検証はプロジェクトのルートで`node scripts/verify-*.cjs`を各ファイルについて実行します。

## 開発用の表示デバッグ

`index.html#debug`（または`?debug=1`）で開くと「デバッグ」ボタンが表示されます。デバッグ中は履歴・設定をメモリ内で扱い、通常の保存データを書き換えません。再読み込みで元に戻り、「実データに戻す」では起動時の状態にテストデータを戻します。

- 対象ユニットまたは全ユニットの進捗・任意の全問正解回数
- Vocxの全4モード、DojoのPart 1・2、問題数、カウントダウンの有無
- 強制正解・不正解、次の問題、指定の問題番号への移動、経過時間
- 一時停止・途中再開、全問正解・半分正解・全問不正解の結果画面
- 効果音の再生、ヒント・効果音設定、プロフィール名
- 長い問題文への差し替え、現在の状態・正解の確認、テストデータの初期化

クイズ中・結果画面では右端の「デバッグ」から操作できます。問題番号への移動ではテスト中の回答記録をリセットします。デバッグを終了するにはURLの`#debug`／`?debug=1`を外して再読み込みしてください。

公開時は後述のビルドでデバッグ機能を自動的に除外します。開発に必要なソースは削除しません。

## GitHub Pagesへの公開

GitHub Actionsの「Publish GitHub Pages」を手動実行すると、検証後に`node scripts/build-pages.cjs`で公開版を生成して配信します。`main`へのpushだけでは公開されません。

公開版は`work/pages/`に生成され、デバッグ画面・デバッグ操作コード・開発ファイルを含みません。ローカルのソースとデバッグ機能は残るため、この公開方法では手動削除は不要です。素材は使用中のものだけをコピーし、フォントのライセンスも同梱します。
