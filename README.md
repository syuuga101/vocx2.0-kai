# Vocx & Dojo

スマートフォン向けの英単語・問題演習アプリです。HTML / CSS / JavaScriptで動作します。

Vocxの「鬼モード」は、ユニットの20語を1回ずつ出題し、日本語→英単語4択・英文空欄4択・英文空欄入力をランダムな順番で混ぜます。各形式は6〜7問ずつです。途中保存・再開と全問正解の記録にも対応しています。

## ファイル構成

- `index.html`：画面構造
- `ui.css`：テーマ・レイアウト
- `app.js`：出題・判定・保存・操作
- `data.js`：学習データのフォールバック
- `vocx/`・`dojo/`：学習データ
- `sw.js`：PWAキャッシュ。配信ファイルを更新するときは`CACHE_NAME`も更新します。
- `sys/`：使用中のPWA・モードアイコンと英字フォント（ライセンス同梱）
- `se/`：効果音
- `debug.js`：ローカル開発用のデバッグ操作（公開版から除外）
- `scripts/`：Node.jsで実行する簡易検証

## 学習データの更新

`vocx/*.csv`・`dojo/*/part*.json`を編集したら、`node scripts/build-data.cjs`で軽量な`data.js`を再生成します。直接HTMLを開く場合やオフライン時も最新データを使えるよう、生成したファイルも一緒に保存してください。HTTP配信時は引き続きCSV・JSONを読み込みます。

PWAは画像・通常の音声取得をキャッシュ優先、HTML・CSS・JavaScript・学習データはネットワーク優先で読み込みます。更新時は`sw.js`の`CACHE_NAME`を変更してください。

検証はプロジェクトのルートで`node scripts/verify-*.cjs`を各ファイルについて実行します。

## 開発用の表示デバッグ

`index.html#debug`（または`?debug=1`）で開くと「デバッグ」ボタンが表示されます。デバッグ中は履歴・設定をメモリ内で扱い、通常の保存データを書き換えません。再読み込みで元に戻り、「実データに戻す」では起動時の状態にテストデータを戻します。

- 対象ユニットまたは全ユニットの進捗・任意の全問正解回数
- Vocxの全4モード、DojoのPart 1・2、問題数、カウントダウンの有無
- 強制正解・不正解、次の問題、指定の問題番号への移動、経過時間
- 一時停止・途中再開、全問正解・半分正解・全問不正解の結果画面
- 効果音の再生、ヒント・効果音設定、プロフィール名
- 長い問題文への差し替え、現在の状態・正解の確認、テストデータの初期化

クイズ中・結果画面では右端の「デバッグ」から操作できます。問題番号への移動ではテスト中の回答記録をリセットします。デバッグを終了するにはURLの`#debug`／`?debug=1`を外して再読み込みしてください。

公開時は後述のビルドでデバッグ機能を自動的に除外します。開発に必要なソースは削除しません。

## GitHub Pagesへの公開

GitHub Actionsの「Publish GitHub Pages」を手動実行すると、検証後に`node scripts/build-pages.cjs`で公開版を生成して配信します。`main`へのpushだけでは公開されません。

公開版は`work/pages/`に生成され、デバッグ画面・デバッグ操作コード・開発ファイルを含みません。ローカルのソースとデバッグ機能は残るため、この公開方法では手動削除は不要です。素材は使用中のものだけをコピーし、フォントのライセンスも同梱します。
